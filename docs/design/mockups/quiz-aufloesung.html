Schnellstes Feedback, kein Warten auf Animation, Frage und Antwort bleiben zusammen sichtbar. Aber keine Fläche für eine Erklärung — nur die nackte Korrektur.

B

Karte dreht um (Empfehlung)

Ein einziges Bewegungsprinzip für Flashcards und Quizfragen — im Hybrid-Bundle fühlt sich alles gleich an. Die Rückseite trägt Verdikt, Lösung und ein optionales Erklärfeld, das die Lehrerin per MCP mitgeben kann.

C

Beides: einfärben, dann drehen

Buttons färben sich sofort, nach einem Moment dreht die Karte zur Erklärung. Doppeltes Feedback, aber auch doppelte Bewegung pro Frage — bei 20 Fragen kann das nerven.

Was daran hängt

Wenn du B nimmst, bekommt jede Quizfrage in der Datenbank ein optionales Feld erklaerung, das die Lehrerin per MCP füllen kann („Zagreb liegt im Landesinneren, Split und Dubrovnik an der Küste"). Bei A würde das Feld nirgends hinpassen — dann lassen wir es weg.
